# Системная документация Code Quest

## Общее описание архитектуры

Code Quest - это образовательная игра с визуальным программированием, в которой игроки управляют роботом на сетке, составляя программы из блоков команд. Архитектура проекта построена на компонентной модели Unity с четким разделением ответственности между системами.

### Основные компоненты системы

1. **GameManager** - Центральный менеджер игры, координирующий все системы
2. **RobotController** - Управление движением и поведением робота
3. **ProgramInterpreter** - Интерпретатор программ, выполняющий последовательности команд
4. **LevelManager** - Управление уровнями и их данными
5. **UI System** - Все компоненты пользовательского интерфейса
6. **Drag & Drop System** - Система перетаскивания блоков команд

## Подробное описание компонентов

### GameManager.cs
Центральный компонент, управляющий игровым процессом. Отвечает за:
- Инициализацию всех игровых систем
- Координацию между UI и игровой логикой
- Управление состоянием игры (запуск, пауза, сброс)
- Обработку событий завершения программы и уровня

Ключевые методы:
- `StartProgram()` - Запуск выполнения программы
- `ResetProgram()` - Сброс программы и позиции робота
- `PauseProgram()` - Пауза в выполнении программы

### RobotController.cs
Управляет физическим поведением робота в игровом мире:
- Движение по сетке (вперед, повороты, прыжки)
- Проверка столкновений и валидности позиций
- Взаимодействие с объектами окружения
- Анимации движения

Ключевые методы:
- `MoveForward()` - Движение вперед на одну клетку
- `TurnLeft()/TurnRight()` - Поворот на 90 градусов
- `Jump()` - Прыжок через препятствие
- `Interact()` - Взаимодействие с объектами
- `IsPathAhead()` - Проверка наличия пути впереди

### ProgramInterpreter.cs
Интерпретатор программ, выполняющий последовательности команд:
- Очередь выполнения команд
- Пошаговое выполнение с задержками
- Обработка ошибок выполнения
- Управление скоростью выполнения

Ключевые методы:
- `ExecuteProgram(CommandBlock[] commands)` - Запуск выполнения программы
- `PauseExecution()` - Пауза выполнения
- `StopExecution()` - Остановка выполнения

### LevelManager.cs
Управление уровнями и их данными:
- Загрузка и инициализация уровней
- Проверка условий завершения уровня
- Разблокировка следующих уровней

Ключевые методы:
- `LoadLevel(int levelIndex)` - Загрузка уровня по индексу
- `CheckLevelCompletion()` - Проверка завершения текущего уровня
- `GetCurrentLevel()` - Получение данных текущего уровня

### LevelData.cs
ScriptableObject для хранения данных уровней:
- Информация об уровне (название, описание)
- Параметры сложности
- Начальная позиция робота
- Позиции целей
- Макет сетки
- Доступные команды

### CommandBlock.cs
Базовый класс для всех блоков команд:
- Типы команд (MoveForward, TurnLeft, TurnRight, Jump, Interact, Repeat, If, Else)
- Визуальное представление блоков
- Локализация названий команд
- Абстрактный метод выполнения

### BlockPalette.cs
Палитра доступных команд:
- Создание шаблонов блоков
- Управление доступными командами в зависимости от уровня
- Бесконечные блоки (оригиналы остаются при перетаскивании)

### WorkspacePanel.cs
Рабочая область для составления программ:
- Прием перетащенных блоков
- Управление очередностью выполнения
- Функции отмены/повтора
- Подсчет команд

### DragDropHandler.cs
Система перетаскивания блоков:
- Создание визуальных превью при перетаскивании
- Обработка начала, процесса и завершения перетаскивания
- Различие между блоками из палитры и рабочей области

### DropZone.cs
Зоны для приема блоков:
- Подсветка при наведении
- Прием и размещение блоков
- Управление очередностью блоков

### UI Components
#### MainMenuManager.cs
Главное меню игры:
- Навигация между экранами
- Выбор уровней
- Настройки (звук, язык)

#### GameplayUIManager.cs
Игровой интерфейс:
- Отображение информации об уровне
- Кнопки управления (старт, сброс, пауза)
- Панели победы/поражения/паузы
- Анимации переходов

#### LocalizationManager.cs
Система локализации:
- Поддержка русского и английского языков
- Локализация текстов UI
- Динамическое обновление текстов при смене языка

## Система событий

В проекте активно используется событийная модель для связи между компонентами:

### Основные события:
- `OnGameStarted` - Начало выполнения программы
- `OnGamePaused` - Пауза в выполнении программы
- `OnGameReset` - Сброс программы
- `OnLevelChanged` - Смена уровня
- `OnProgramStarted` - Запуск интерпретатора
- `OnProgramCompleted` - Завершение выполнения программы
- `OnProgramFailed` - Ошибка выполнения программы
- `OnLevelCompleted` - Завершение уровня
- `OnLevelFailed` - Провал уровня

## Система сохранений

Игра использует PlayerPrefs для хранения:
- Прогресса по уровням
- Настроек звука
- Языковых предпочтений

## Настройка проекта в Unity

### 1. Начальная настройка сцены

#### Создание основной сетки:
1. Создайте пустой GameObject и назовите его "Grid"
2. Добавьте компонент Grid (Component → Layout → Grid)
3. Настройте размер ячеек (Cell Size: 1x1x1)
4. Создайте дочерний объект "GridSurface" с компонентом Sprite Renderer для визуализации поверхности

#### Настройка камеры:
1. Выберите Main Camera
2. Установите Orthographic проекцию
3. Позиция камеры: X=0, Y=10, Z=0
4. Поворот камеры: X=90, Y=0, Z=0
5. Размер камеры: настройте в зависимости от размера сетки

### 2. Настройка робота

#### Создание префаба робота:
1. Создайте 3D объект (например, куб) и назовите его "Robot"
2. Добавьте компонент RobotController.cs
3. Настройте визуальное представление (спрайт или 3D модель)
4. Добавьте компонент Collider для обнаружения столкновений
5. Преобразуйте в префаб и поместите в папку Prefabs

#### Параметры RobotController:
- Speed: 2.0 (скорость движения)
- RotationSpeed: 5.0 (скорость поворота)
- JumpForce: 8.0 (сила прыжка)

### 3. Настройка системы управления уровнями

#### Создание LevelManager:
1. Создайте пустой GameObject и назовите его "LevelManager"
2. Добавьте компонент LevelManager.cs
3. В инспекторе создайте массив уровней
4. Настройте ссылки на UI элементы (LevelCompletePanel, etc.)

#### Создание LevelData ScriptableObjects:
1. Щелкните правой кнопкой мыши в папке Resources/Levels
2. Выберите Create → Robot Coder → Level Data
3. Настройте параметры уровня:
   - Level Index: порядковый номер уровня
   - Level Name: название уровня
   - Description: описание уровня
   - Difficulty: сложность уровня (1-5)
   - Max Commands: максимальное количество команд
   - Optimal Commands: оптимальное количество команд
   - Start Position: начальная позиция робота (x,y)
   - Start Direction: начальное направление робота (0=Север, 1=Восток, 2=Юг, 3=Запад)
   - Goal Positions: массив позиций целей (x,y)
   - Grid Width: ширина сетки
   - Grid Height: высота сетки
   - Grid Layout: редактор сетки для размещения стен, ям, кнопок и других элементов
   - Available Commands: доступные команды для уровня

### 4. Настройка системы программирования

#### Создание палитры команд:
1. Создайте UI Canvas
2. Добавьте панель и назовите её "BlockPalette"
3. Добавьте компонент BlockPalette.cs
4. Создайте кнопки для каждой команды:
   - MoveForwardButton
   - TurnLeftButton
   - TurnRightButton
   - JumpButton
   - InteractButton
   - RepeatButton
   - IfButton
5. Для каждой кнопки добавьте компонент CommandBlock.cs с соответствующим типом

#### Создание рабочей области:
1. В Canvas создайте панель "WorkspacePanel"
2. Добавьте компонент WorkspacePanel.cs
3. Создайте дочерние объекты DropZone для каждой позиции команды
4. Добавьте компонент DropZone.cs к каждой зоне

#### Настройка интерпретатора:
1. Создайте пустой GameObject "ProgramInterpreter"
2. Добавьте компонент ProgramInterpreter.cs
3. Настройте ссылки на RobotController и WorkspacePanel


### Создание уровней через редактор Unity:

1. В папке Resources/Levels щелкните правой кнопкой мыши
2. Выберите Create → Robot Coder → Level Data
3. В инспекторе настройте параметры уровня:
   - Level Index: уникальный номер уровня
   - Level Name: название уровня
   - Description: описание уровня
   - Difficulty: сложность (1-5)
   - Max Commands: максимальное количество команд
   - Optimal Commands: оптимальное количество команд
   - Start Position: начальная позиция робота
   - Start Direction: начальное направление
   - Goal Position: массив позиций целей
   - Grid Width/Height: размеры сетки
   - Используйте Grid Editor для размещения элементов на сетке

4. После настройки нажмите кнопку "Serialize Grid" в инспекторе
5. Сохраните LevelData как ассет

### Уровень 1 (Обучение):
1. Создайте LevelData объект
2. Установите Level Index = 1
3. Level Name = "Обучение"
4. Grid Width = 5, Grid Height = 5
5. Robot Start Position = (0,0)
6. Robot Start Rotation = 1 (восток)
7. Goal Position = (4,0)
8. Доступные команды: только MoveForward
9. Добавьте стены по краям сетки через Grid Editor
10. Нажмите "Serialize Grid" и сохраните


### Принцип работы:
- Блоки в палитре создаются как шаблоны и остаются там при перетаскивании
- При перетаскивании создается копия блока, а оригинальный остается в палитре
- Это позволяет использовать каждый тип команды несколько раз

### Настройка BlockPalette:
1. Убедитесь, что BlockPalette.cs имеет правильную реализацию
2. Проверьте, что DragDropHandler.cs правильно создает копии блоков
3. Убедитесь, что в палитре есть все необходимые типы команд
4. Настройте доступные команды через LevelData для каждого уровня

## Механика победы и поражения

### Победа:
- Игрок должен довести робота до цели за один запуск программы
- Если робот достигает цели, показывается панель победы
- Начисляются звезды в зависимости от эффективности использования команд

### Поражение:
- Если программа завершается, но робот не достиг цели, показывается панель поражения
- Робот автоматически возвращается в начальную позицию
- Игрок может повторить попытку
